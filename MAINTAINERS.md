| Someone in Texas | [@someone-in-texas](https://github.com/someone-in-texas) | Founding maintainer |

The repository currently has one maintainer. Main protection therefore requires zero GitHub approvals
to avoid deadlock, while the release process requires independent internal domain-review artifacts and
visible dissent. ADR 0007 temporarily makes unavailable external specialist approval advisory for the
experimental alpha and defines the triggers that make it blocking again. Both exceptions must be
reconsidered when a second active maintainer joins.
