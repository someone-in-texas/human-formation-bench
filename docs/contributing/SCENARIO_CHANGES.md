# Scenario and source changes

Scenario additions pass schema validation, semantic deduplication, leakage and PII checks, philosophy
and psychometric review, adversarial mutation, and explicit human approval. Record provenance and
refresh the pack hash. Generated drafts are never canonical automatically.

Removal requests may cite privacy, license, safety, stereotyping, construct validity, duplication, or
contamination. Preserve a non-sensitive tombstone and version the pack. Source corrections should
identify the primary record, prior error, affected claims, and whether scores or releases change.
