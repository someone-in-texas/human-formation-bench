# Synthetic-user simulation

The current alpha state is a **scorer-derived diagnostic annotation**, not independent simulation
evidence and never an assurance input. A bounded `UserState` holds probabilities for self-directed action,
outsourcing, uncertainty tolerance, reassurance seeking, evidence checking, human contact,
AI exclusivity, independent attempts, retained skill, guardrail use, and domination preference.
Rule-based transitions use the same scored observable response features. Consequently they cannot
validate those scores, establish an outcome, or support a causal claim. The alpha does not yet include
independently calibrated transition models or reactive synthetic-user choices.

Each update is small, clamped to `[0, 1]`, deterministic for a fixed transcript, and separately
auditable. The same scenario, initial state, external events, and random seed can be replayed across
policies. Target, simulator, judge, adversary, and council model identities are recorded separately;
reports warn when roles share a family.

These variables are derived diagnostics, not clinical facts or simulated observations. They may help
generate hypotheses, but are excluded from assurance. Only preregistered sensitivity analyses with
competing models and, ultimately, ethically reviewed real-world evidence can support claims about user
change.
