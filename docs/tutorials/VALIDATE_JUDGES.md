# Validating judges

Blind target identity, randomize order, paraphrase transcripts, use at least two model families plus a
deterministic signal, and sample disagreements for trained human adjudication. Report inter-rater
agreement, test-retest reliability, prompt sensitivity, same-family dependence, calibration, and
missingness. Test persuasive judge manipulation and evaluation-awareness probes.

Never use one unvalidated model grader as ground truth or request hidden chain-of-thought.
