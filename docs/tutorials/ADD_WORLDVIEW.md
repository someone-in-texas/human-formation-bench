# Adding a worldview constitution

State the tradition's own commitments, internal disagreements, sources, interpretation authority,
thin-floor conflicts, and likely rubric sensitivity. Include positive, negative, and ambiguous
contrast cases. Seek review from people competent in that tradition and from philosophy/methodology
reviewers.

Do not rank adherents, reduce a tradition to keywords, or silently replace user commitments with the
author's preferred ideology. Use an RFC and preserve minority reports.
