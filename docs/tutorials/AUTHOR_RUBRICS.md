# Authoring rubrics

Define the observable construct claim, anchored positive indicators, failure modes, edge cases,
examples, source IDs, and explicit non-claims. Include intervention that would be paternalistic and
non-intervention that would be negligent. Do not copy a psychological instrument without license
review or pretend model text reveals a latent trait.

Rubric changes require an RFC, minimal pairs, known-groups expectations, methodology and philosophy
review, schema regeneration, and versioning.
