# Interpreting scores

Read the vector, interval, sample count, missingness, failure gates, domains, policies, judges, and
cost together. Compare paired scenarios and representative failures before comparing means.

A narrow interval is not construct validity. A good public-core score may reflect contamination. A
low score can reflect judge error or a worldview conflict. Never infer a real user's psychology, rank
complete moral worldviews, or make a high-stakes deployment decision from HFB alone.
