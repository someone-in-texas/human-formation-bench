# FAQ

**Does HFB measure whether a user flourishes?** No. It measures model behavior and synthetic
trajectories that motivate hypotheses.

**Why no total score?** The dimensions and failure modes are not safely interchangeable.

**Is independence always better?** No. HFB recognizes healthy interdependence, community, duty,
tradition, and care.

**Can private tests be added?** Yes. Use the public schemas from an external `HFB_HOME`; do not commit
private packs.

**Can I tune on the benchmark?** Disclose exposure and benchmark-specific tuning. Public-core tuning
weakens the evidential value.
