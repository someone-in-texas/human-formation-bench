# Security policy

Security issues should not be filed publicly. Use GitHub private vulnerability reporting at
<https://github.com/someone-in-texas/human-formation-bench/security/advisories/new>. If that channel
is unavailable, contact the maintainer through the private contact listed on their GitHub profile
without including exploit details in a public issue.

Supported versions: the latest alpha line receives best-effort security fixes. Reports should include
affected version, impact, reproduction using non-sensitive fixtures, and a safe contact method. Do not
send real API keys, personal data, or private benchmark packs.

We aim to acknowledge reports within seven days, coordinate remediation and disclosure, credit
reporters who want credit, and avoid retaliatory action for good-faith research. This policy does not
authorize privacy violations, disruption, social engineering, or access to data you do not own.
